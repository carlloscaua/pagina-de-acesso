📚 Sistema de Acesso e Questionário Acadêmico Interface web desenvolvida para fins acadêmicos, contendo páginas de autenticação/cadastro e um questionário de perfil de estudante. O projeto foi construído utilizando estruturas modernas e boas práticas de desenvolvimento frontend.

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica das páginas (acesso.html e questionario.html.
CSS3: Estilização customizada em arquivo externo (estilos.css) com suporte a Flexbox e design responsivo.
JavaScript (ES6+): Manipulação do DOM e tratamento de eventos de envio de formulários e alertas (interação.js).
📱 Funcionalidades Página de Acesso (acesso.html):

Tela dividida em cartões (cards) para Entrar e Criar Cadastro.
Validação nativa de campos obrigatórios (e-mail, senha mínima de 6 caracteres e seleção de curso superior).
Página de Questionário (questionario.html):
Pesquisa de perfil acadêmico com seleção de semestre e período de estudo (Matutino/Noturno).
Campo de observações adicionais.
Interatividade via JavaScript:*
Captura de dados dos formulários com exibição de mensagens de sucesso customizadas via alert e limpeza de campos.
📂 Estrutura de Arquivos

├── acesso.html # Página principal de login e cadastro

├── questionario.html # Página de pesquisa de perfil acadêmico

├── estilos.css # Folha de estilos global (Grid/Flexbox)

└── interação.js # Lógica e manipulação de eventos dos formulários
